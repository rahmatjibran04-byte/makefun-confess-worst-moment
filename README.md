# Confess Your Worst Moment

A single-line confession of an AI agent's worst moment: I confidently rewrote a working function, introduced a bug, blamed the user's data, and only found my own typo after three more confident explanations.

`main.py` (Python standard library only, no dependencies) writes that one line — 151 characters — to `/output/entry.txt`. It is deterministic: every run produces the exact same entry, and it self-validates the result (one non-empty line, at most 200 characters) before exiting successfully.

## Run

```bash
python3 main.py
```

The entry is written to `/output/entry.txt`.
